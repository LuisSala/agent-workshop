# Setup & Configuration

## Requirements
Note: We'll try to simplifly by using uv to manage as many dependencies as possible.

- **Mac or Linux Workstation:** This project is optimized for UN*X-like environments. Windows users may need to use WSL2.
- **uv package manager:** https://github.com/astral-sh/uv
- **Google Cloud SDK:** https://cloud.google.com/sdk/docs/install

# Recommended
- **Google Antigravity or VS Code-compatible IDE:** https://antigravity.google/ or https://code.visualstudio.com/

## Included Resources
- **Agent Starter Pack:** https://github.com/google/agent-starter-pack
- **Agent Development Kit (ADK):** https://github.com/google/agent-development-kit
- **Vertex AI SDK for Python:** https://github.com/googleapis/python-aiplatform

## Installation
1. Open this project's workspace in your IDE of choice (e.g. Antigravity, VS Code, etc.) and open a terminal.
2. Run `uv sync` to install dependencies.
3. Run `.venv/bin/activate` to activate the virtual environment. Your IDE might also do this for you automatically.

## Googler-specific Instructions
- **Run `gcert`:** To allow Python package installation to proceed.
