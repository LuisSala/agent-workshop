# Module 1: Foundation

In this module, we will explore the fundamentals of the Google Agent Development Kit (ADK).

We start with a basic agent that can answer questions about the current time and weather.
This agent is representative of the default agent generated by the Agent Starter Pack

## Your Objectives

### 1. Run the ADK Web UI

Execute `make playground` which is a shortcut for `adk web path/to/agent`.

Try talking to your agent and see what it can do.

### 2. Add a custom function: get_weather()

Your objective is to add a function tool that returns the current weather conditions for a given city.
Specifically, for a given city, the tool should return a random temperature (e.g. -10 to 40 degrees Celsius) and weather conditions (sunny, cloudy, raining, etc.).
